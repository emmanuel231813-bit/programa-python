## Problema Desarrollado
Problema 3 - Auditoría de Inventario y Reabastecimiento

## Descripción

Este proyecto desarrolla una solución en Python para realizar una auditoría de inventario y determinar las cantidades necesarias para el reabastecimiento de productos que se encuentran por debajo del stock mínimo requerido.

## Archivos del Repositorio

- Fase5_EmmanuelOrellano_Inventario.pdf → Informe completo de la actividad.

## Funcionalidades

- Gestión de inventario mediante listas anidadas.
- Uso de funciones.
- Uso de estructuras condicionales.
- Uso de ciclos repetitivos.
- Generación de reportes de reabastecimiento.
